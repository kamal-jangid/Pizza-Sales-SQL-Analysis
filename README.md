# 🍕 Pizza Sales SQL Analysis

## 📌 Project Overview

This project focuses on analyzing pizza sales data using SQL to identify sales trends, customer ordering patterns, revenue performance, and product performance.

The main objective is to extract meaningful insights from pizza sales data by writing SQL queries.

## 🎯 Project Objectives

- Analyze total orders and total revenue.
- Identify the most popular pizza sizes and types.
- Analyze sales by pizza category.
- Understand hourly order trends.
- Calculate revenue contribution by pizza type.
- Analyze cumulative revenue.
- Identify top-performing pizzas in each category.
